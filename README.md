🚖 Uber Rides Data Analytics Dashboard

Uber Ride Data Analytics Dashboard is an end-to-end analytics project that explores ride booking data to identify patterns in demand, cancellations, and revenue. Using Python-based exploratory data analysis and an interactive Streamlit dashboard, raw booking data is transformed into actionable business insights and key performance metrics.

📊 Project Objectives

Analyze ride booking patterns across time and vehicle types

Identify peak demand periods for operational planning

Understand customer and driver cancellation behavior

Evaluate revenue contribution by vehicle type

Present insights through an interactive dashboard for decision-making

🛠️ Tech Stack

Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Dashboard: Streamlit

Tools: Jupyter Notebook, VS Code

📂 Dataset Overview

The dataset contains detailed ride-booking information, including:

Booking date and time

Booking status (Completed, Cancelled, Incomplete)

Vehicle type

Booking value (revenue)

Ride distance

Customer and driver ratings

Cancellation indicators and reasons

Engineered features such as hour, day, and month

📈 Key Features
1️⃣ KPI & Demand Overview

Total bookings and total revenue

Cancellation rate

Peak booking hours and days

Hourly and day-wise demand trends

Business Value: Helps understand demand cycles and optimize driver availability.

2️⃣ Cancellation Root-Cause Analysis

Customer vs driver cancellations

Top cancellation reasons

Time-based cancellation trends

Business Value: Identifies operational issues and opportunities to reduce ride drop-offs.

3️⃣ Revenue & Vehicle Performance Analysis

Revenue contribution by vehicle type

Average ride distance by vehicle

Peak revenue time slots

Business Value: Supports pricing strategy and fleet optimization.

🎛️ Interactive Dashboard Features

Dynamic filters for time and vehicle type

Real-time KPI updates

Visual storytelling using charts and metrics

Downloadable filtered data (optional)
